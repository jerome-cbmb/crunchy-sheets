# Crunchy Sheets

## Overview
Crunchy Sheets is an AI-powered Google Sheets add-on that transforms financial modeling and analysis for founders and SMBs.

## Key Features
- 🤖 AI-powered financial insights
- 📊 Workbook state string serialization
- 🔬 Dynamic skill routing (Sonnet/Opus)
- 🔒 Non-destructive analysis
- 🚀 Designed for founders who work in Google Sheets

## Development Status
- Architecture: Apps Script + Cloud Functions
- Current Version: 0.1.0-alpha
- Primary Use Case: Personal finance & SMB financial modeling
